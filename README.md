# Messprotokoll-App

Web-App (PWA) zum Erfassen von VDE-Messwerten auf dem Handy: Projekte, Prüfungen, Deckblatt,
Prüfpunkte, Stromkreisliste und Unterschrift. Die Daten bleiben lokal im Browser des Geräts.

Hinweis: Keine Kundendaten und keine Firmenvorlagen (Excel, Logos) in dieses Repository hochladen.
